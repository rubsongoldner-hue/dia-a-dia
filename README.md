# Dia a Dia

Checklist diário para iPhone e computador: tarefas do dia, listas, rotinas com horário,
prazos, avisos, ditado por voz e sincronização opcional com o Google Drive e a Agenda Google.

Funciona offline e guarda os dados só no aparelho (e no seu Drive, se você conectar).

## Instalar no iPhone
Abra o endereço deste site no Safari → Compartilhar → Adicionar à Tela de Início.
